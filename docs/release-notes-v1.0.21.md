# 轻PDF编辑器 v1.0.21

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

修复打印方向「怎么选都是横向」的问题，并恢复双面打印的「长边 / 短边翻转」选项。

## 本次改动

### 1. 打印方向不生效（自动 / 纵向 / 横向结果都一样）

打印对话框构造 `QPrinter` 时有两处问题：

- 完整设置分支沿用 `printer.pageLayout().pageSize()`（保留驱动默认纸张）。某些网络复合机
  （如 iR C3020）默认纸张是横向，只改方向不改尺寸，驱动会再次翻回横向。
- 更关键的是「降级重试」分支（驱动拒绝自定义 DEVMODE 时改用 `full=False`）**完全没有施加任何页面设置**，
  直接退回驱动默认值。QPainter 在这类驱动上首次构造常会失败并触发降级，于是无论界面选什么方向，
  最终都按驱动默认的横向打印——这正是「预览是对的、打印却总是横向」的根源。

v1.0.21 把方向 / 纸张设置抽成独立方法 `_apply_orientation()`：

- 显式 `setPageSize(A4)`，不沿用驱动默认纸张；
- 用 `QPageLayout(A4, 方向, 页边距)` 一次性写入尺寸 + 方向，个别 Qt 版本不接受时退化为分步设置；
- **完整分支与降级分支都调用它**——降级只跳过最容易被驱动拒绝的双面 / collate 设置，方向 / 纸张 / 份数一律保留。

### 2. 双面打印的「长边翻转 / 短边翻转」无法选择

`_sync_duplex()` 方法原本只在 `__init__` 里调用一次，`duplex_check.toggled` 信号从未连接到它，
导致勾选「双面打印」后两个翻转单选项永远保持禁用。

v1.0.21 在 `_wire()` 中补上 `self.duplex_check.toggled.connect(self._sync_duplex)`：
勾选双面即可选择长边 / 短边翻转，取消勾选自动禁用。

## 验证

- 离屏方向验证：`auto / portrait / landscape` × `完整 / 降级` 六个组合，纸张方向全部正确（竖向 / 横向），纸张尺寸均为 A4。
- 双面接线验证：勾选双面后长边 / 短边 radio 由禁用变可用；取消勾选后重新禁用。
- 端到端打印验证：真正走一遍打印输出到 PDF，纵向成品 595×842、横向成品 842×595，方向确实写进成品纸张。
