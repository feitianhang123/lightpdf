# 轻PDF编辑器 v1.0.14

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

修正 v1.0.13「一动就标整行」的问题：高亮 / 下划线 / 删除线现在**横向精确、纵向宽松**——
不用框住整行高度，但**画多长就标多长**：中文画到第几个字就标到第几个字，英文可以标到半个单词。

## 怎么用

1. 在工具栏选 **高亮**、**下划线** 或 **删除线**。
2. 按住鼠标左键，**沿要标记的文字横向划过**：
   - 中文：从某个字划到另一个字，只标这两个字之间的内容，不再标整行；
   - 英文：可以只标一个单词的一部分（例如 `ALPHA` 里的前四个字母）；
   - 纵向不用精准——横向划一条细线、或框偏到行的上/下缘都能命中（±1.5 pt 容差）。
3. 松开鼠标完成标注；相邻被选中的字会合并成一条连续高亮，不会碎成小块。误操作用「撤销」恢复。

## 为什么 v1.0.13 会标整行

PyMuPDF 对没有空格的中文会把**整句话当成一个 word**（例如 224 pt 宽的一整行）。
v1.0.13 的选词粒度是「词」，框碰到这个大 word 的任何一部分，整行就都被标上了。
v1.0.14 改用 `page.get_text("rawdict")` 的**字符级**坐标来判定横向范围，所以能精确到第几个字；
纵向仍按行吸附，保留「不用精准框住行高」的便利性。

| 维度 | v1.0.13 | v1.0.14 |
|---|---|---|
| 纵向 | 行吸附，宽松 | 不变，仍宽松（细线也能标） |
| 横向 | 词级 → 中文整句一起标 | 字符级 → 画到第几个字标到第几个字 |
| 高亮形状 | 整词块 | 相邻字符合并成连续条 |

实现位置：`app/core/annotations.py::words_for_markup`（`pad_x=0.5` 横向微容差、`pad_y=1.5` 纵向容差）。
界面配色、布局、工具栏未改动。

## 验证

- 21 项断言全部通过：
  - **横向精确**：中文画 3 字→标 3 字、画 6 字→标 6 字、只框 1 字→标 1 字；英文按字母边界精确；
  - **纵向宽松**：1 pt 高的细线、框偏到行下缘 2 pt 仍能命中；
  - **不乱画**：行间空白、页面空白、框到第 2 行不碰第 3 行；
  - **批注类型**：HighLight / Underline / StrikeOut 正确写入，原文保持不变；空白页不报错。
- `app/` 与 `run_app.py` 全量 `compileall` 通过。
