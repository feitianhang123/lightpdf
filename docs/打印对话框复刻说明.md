# 打印对话框复刻说明（对照 Foxit PDF Editor 11）

本工程的「打印」对话框不是仿制，而是**按原版程序的 Win32 对话框资源 1:1 还原**。

## 一、原版来源

| 项 | 值 |
| --- | --- |
| 原程序 | Foxit PDF Editor **11.0.0.49893**（Foxit Software Inc.） |
| 安装包 | `GA_PDFEditor_AllLang_Online_PhantomPDFWebsite_Bundle_v11.0.0.49893.exe`（WiX Burn 引导器） |
| 主程序 | `FoxitPDFEditor.exe`（PE32，MSVC 2017，MFC + 静态 Qt） |
| 打印对话框 | 资源 **DIALOG 7792**，标题 `Print`，尺寸 **531 × 308** 对话框单位，**63** 个控件 |
| 相关对话框 | 7785 `Advanced` · 7789 Scale 选项 · 7794 `Batch Print` · 7795 `Page Range Options` |

完整控件清单见 [`foxit-print-dialog-spec.json`](foxit-print-dialog-spec.json)（由资源直接反解）。

## 二、提取方法（可复现）

```
# 1) 解包 Burn 引导器
7z x Setup.exe                 # 或用 WiX dark.exe
#    → 定位 MSCF(CAB) 附加容器 → 切出 .cab
7z x foxit_attached.cab        # → a0..a16 (MSI)
7z x a16 media1.cab            # → 取 media1.cab
7z x media1.cab FoxitPDFEditor.exe

# 2) 反解对话框资源
python E:\PE-Tools\10_资源解析\pe_resources.py dialogs FoxitPDFEditor.exe -o out
```

> 注意：Resource Hacker 在这种「.rsrc 达 21MB / 上千资源」的程序上会静默失败，
> 必须用 `pe_resources.py`（纯 Python 解析 PE 资源目录树）。详见工具箱 README 的踩坑记录。

## 四、与原版的差异（诚实说明）

1. **布局容器的宽度**：原版用对话框单位绝对定位（531×308 DU ≈ 797×462 px）；本实现用 Qt 布局，
   窗口约 **1000×640**，比例接近但非像素级一致。
2. **Print Handling 四选项**：原版一行四个（文字换行），本实现为 2×2 网格（Qt 单选按钮不换行）。
3. **Tile Large Pages**：原版用独立的「Page Zoom / Overlap / Cut Marks / Labels」对话框，
   本实现按相同参数在页面上直接平铺。
4. **`Summarize Comments` / `Simulate Overprinting`**：保留了控件，但仅作开关记录，未实现完整语义。
5. **`Advanced`（PCL 优化）**：原版用于自动检测 PCL 打印机；本实现沿用系统打印驱动并给出说明。
6. **Form Fields only**：本工程无表单域概念，按「文档」处理。

## 六、1.0.3 修复记录（打印向）

| # | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 「每张多页」时预览是横向、实际打印却是纵向 | `_paper_canvas()` 里 `max(sw, content.width())` 把**纸面撑成了内容的形状**；而打印走 `_landscape()` 的真实纸张，两者不一致 | 纸面宽高比**只由纸张方向决定**，内容等比缩放居中（内容比纸宽/窄时如实出现白边）—— 预览 == 输出 |
| 2 | 刚打开对话框时预览不是完整页，翻页后才正常 | `__init__` 里就调用了 `_update_preview()`，此时预览框尚未完成布局，按错误尺寸缩放；窗口尺寸没变故 `resizeEvent` 不再触发 | 底图与缩放**解耦**：保存全尺寸底图 `_preview_base`，用 `eventFilter(Resize)` + `showEvent` 重新缩放；`resizeEvent` 只缩放不重渲染 |
| 3 | 选 Canon iR C3020 一直打不出来，换别的打印机立刻能打 | 一次性把「页面尺寸 + 方向 + 双面 + 份数」全部写进 DEVMODE 交给驱动；部分网络复合机驱动不接受自定义设置时**直接丢弃任务**，且原失败提示过于笼统 | 加**降级重试**：第二次改用 `ScreenResolution` 且只设份数、完全用驱动默认值；失败时给出具体原因与排查建议（方向/部门 ID/先打印到文件/换驱动） |

**方向解析优先级**（`_landscape()`）：
1. 小册子 → 横向；
2. 方向选「纵向 / 横向」→ 照选；
3. 「自动」→ **多页合一时按网格形状**（1×2、2×3 → 横向；2×2 → 跟随页面），否则跟随文档页面比例。

> 已用 7 组方向组合实测「预览方向 == 输出纸张方向」，全部一致；覆盖 每张2页(自动/纵/横)、普通(自动/横)、每张4页、小册子。
