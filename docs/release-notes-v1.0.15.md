# 轻PDF编辑器 v1.0.15

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

修复打印时「方向」选项把内容也跟着转的问题：**纸张方向由你选，内容始终保持正向**，等比缩放居中。
以横向 A4 发票为例，选纵向时发票会缩小放在纸中间、四周留白，但字是正的，不用歪头看。

## 问题现象

打印一张本来就横着的发票（页面 595×397 pt）时，无论「方向」选自动、纵向还是横向，
输出的发票内容都是**竖向**的：横向纸上内容缩在中间、两边大片留白；纵向纸上内容虽然铺满，
但文字转了 90°。给人的感觉就是「方向选项只换纸，内容不受控」。

## 根因

打印对话框默认勾选「自动旋转」，其逻辑是「只要页面比纸宽就把内容转 90°」，
与方向下拉选的纸张方向互相打架；预览里也写死了「横向纸就把内容转 90°」，
所以预览和输出一起错，看起来像方向选项失效。

## 现在的规则

| 你的选择 | 纸张 | 内容 |
|---|---|---|
| 自动 | 跟随原页面方向（横向发票 → 横向 A4） | 保持原方向、铺满 |
| 纵向 | 纵向 A4 | 保持原方向、等比缩小居中，四周留白 |
| 横向 | 横向 A4 | 保持原方向、铺满 |
| 勾选「旋转内容适配纸张」 | 按所选方向 | 恢复老行为：内容旋转 90° 铺满纸张 |

「旋转内容适配纸张」默认**关闭**；需要内容跟着纸转时再勾选。打印预览与实际输出共用同一套逻辑，所见即所得。
界面其余配色、布局、工具栏未改动，只是给已有复选框换了更准确的名字。

实现位置：`app/ui/dialogs.py` 的 `_maybe_autorotate()`（按纸张方向决定是否旋转）、
`_update_preview()`（预览改用同一函数）、`_wire()`（勾选后刷新预览）。

## 验证

18 项回归断言全部通过：

- 横向发票源文件在自动 / 纵向 / 横向三种方向下，纸张方向正确、内容始终保持横向；
- 纸张尺寸标签与实际输出方向一致；
- 勾选「旋转内容适配纸张」后恢复旧行为（纵向纸旋转横向内容、横向纸保持横向内容）；
- 竖向源文件在三种方向下内容始终保持竖向；
- `app/` 与 `run_app.py` 全量 `compileall` 通过。
