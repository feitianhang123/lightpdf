## 下载

| 系统 | 文件 | 大小 |
|---|---|---|
| Windows（64 位） | `setup.exe` | 89.8 MB |
| 银河麒麟 V10 SP1 / Linux（ARM64，飞腾 / 鲲鹏） | `lightpdf_1.0.4_arm64.deb` | 64.1 MB |

**Windows**：双击 `setup.exe` 按向导安装（默认 `C:\Program Files\轻PDF编辑器`），开始菜单出现「轻PDF编辑器」。

**银河麒麟 / Debian 系（aarch64）**：

```bash
sudo dpkg -i lightpdf_1.0.4_arm64.deb
sudo apt-get -f install     # 若提示缺依赖，自动补齐
```

之后从开始菜单启动，或终端 `lightpdf 文件.pdf`；卸载 `sudo apt-get remove lightpdf`。

## 本次更新

### 打印：修复已签章 PDF 的红色印章 / 电子签章印不出来

**问题**：打开已盖电子章的 PDF（如检验报告、合同），打印时**预览里看不到红章，打印出来也没有**。

**根因**：红章在 PDF 里并不是画在正文中的图形，而是**电子签章域（Signature Widget）的注释外观流**。
打印管线用「不含注释」的方式渲染页面，把这一层整个丢弃了，所以预览和输出都没有章。

**修复**：

- 打印渲染**默认包含注释**——已签章文档打开对话框即可看到红章；
- 在「打印内容」组新增复选框 **「打印印章与电子签章」**，可一键开关：
  - 勾选（默认）→ 打印红色印章、电子签章、图章、批注等注释内容；
  - 取消勾选 → 只打印文档正文，印章不会出现在预览与打印结果中。
- 「打印内容」默认项由「文档」改为**「文档和标记」**；下拉框与复选框**双向联动**，两者永不矛盾。
- 顺带修掉两个旧问题：「每张多页 / 小册子」原先**忽略该开关**（强制带注释）；
  小册子的**预览与输出不一致**。现在 **预览 == 输出 == 开关状态**，所有模式统一。
- 「灰度打印」下红章会转成灰阶**仍然保留**。

### 附：v1.0.3 已包含的打印改进（延续）

打印对话框为**三栏布局**：左「预览」，中「打印范围 / 打印处理」，右「双面 / 方向 / 打印内容 / 输出」。
完整选项：预览（缩放 / 页尺寸 / 纸张 / 翻页滑杆）· 打印范围（当前视图 / 当前页 / 所有页 /
自定义页码 `1,5-9,12` / 子集奇偶 / 逆序）· 打印处理（缩放「无·适合·缩小·自定义%」/ 平铺大页面 /
每张多页 / 小册子）· 双面（长 / 短边翻转）· 自动旋转 / 居中 · 方向 · 打印内容 · 输出 ·
灰度 / 作为图像 / 出血标记 · 份数 / 逐份 · 打印到文件。
