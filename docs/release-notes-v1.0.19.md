# 轻PDF编辑器 v1.0.19

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

骑缝章插入后**只能上下移动、不能左右移动**；拖动任一页时，**同一枚章的所有页切片同步上下移动**，保证打印叠齐后拼成完整印章。

## 本次改动

### 骑缝章切片的编辑规则

v1.0.18 及以前：每页切片是一张独立图片，可以任意拖动、缩放，改一页只动一页 —— 一旦某一页左右挪动或高度不一致，纸张叠起来就拼不出完整的章。

v1.0.19 把同一枚章的所有切片绑定为一个整体：

- **水平锁定**：切片贴在哪一侧页边就固定在哪一侧，不能左右拖动；方向键的左右、属性对话框的 X/宽度/高度全部禁用。
- **垂直联动**：拖动任一页的切片上下移动时，同一枚章的**所有页切片同步移动相同的距离**；方向键上下、属性对话框的 Y 值同样整组联动。从中间页开始盖、或文档里盖了多枚章，都只联动属于同一枚章的那组。
- **不可缩放**：缩放控制点不再显示（拖动手柄也不改变切片大小），避免单片大小变化破坏拼接。
- **保存后仍联动**：分组信息写入 PDF 图片对象的自定义标记（`LightpdfRidingGroup` / `LightpdfRidingSlot`），随文件保存；重新打开文档后仍能识别哪些切片属于同一枚章，继续联动编辑。切片被移动、撤销/重做、重新烘焙回 PDF 时标记都会保留。

### 覆盖的编辑入口

| 入口 | 水平 | 垂直 |
|---|---|---|
| 鼠标拖动切片 | 锁定 | 整组同步 |
| 方向键 ← → | 无效 | — |
| 方向键 ↑ ↓ | — | 整组同步 |
| 属性对话框 | X / 宽 / 高禁用 | 改 Y 整组同步 |

## 验证

- 6 页文档插入两枚章（各 3 页）：分组标记正确（前 3 页同组、后 3 页同组），slot 各自保留。
- 第一组下移 50 pt：3 页切片 y 全部 +50 pt、x 位移为 0；第二组 3 页完全不受影响。
- 保存重开后仍能按 group 识别 3 片并再次联动；`next_riding_group_base` 正确递增。
- UI 冒烟：选中切片 → 材质化 → 垂直联动 → 烘焙回 PDF → 分组标记保留，全链路 7/7 通过。
- 核心联动逻辑 20/20 通过；冻结 exe 字节码核验版本 `1.0.19` 与全部分组/联动符号。
