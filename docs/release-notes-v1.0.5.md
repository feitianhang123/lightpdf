# 轻PDF编辑器 v1.0.5

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 本次更新：删除当前页 → 删除页面（支持一次删多页）

旧版「页面 → 删除当前页」一次只能删一页。v1.0.5 把它升级为「**页面 → 删除页面...**」，
打开一个对话框，既能一键删当前页，也能一次指定任意多页。

### 怎么用

1. 打开 PDF，点「页面 → 删除页面...」（菜单项名称由「删除当前页」改为「删除页面...」）。
2. 在「范围」里二选一：
   - **当前页**（默认）—— 点「删除」即删除正在浏览的那一页，与旧版行为一致；
   - **指定页面（可多页）** —— 在页码框里输入要删的页，输入框已预填当前页码并全选，直接改即可。
3. 下方会实时提示「将删除 N 页：1-3, 5, 8-10」，确认后点「删除」。
4. 删错了用「编辑 → 撤销」恢复。

### 页码写法

| 输入 | 含义 |
|---|---|
| `5` | 删除第 5 页 |
| `1-3,5,8-10` | 删除第 1、2、3、5、8、9、10 页 |
| `3-1` | 自动纠正为 `1-3` |
| `2,2,2` | 自动去重，只删第 2 页 |
| `1-3，5` | 中文逗号同样支持 |
| `0`、`abc`、`99`（超出总页数） | 自动忽略，并在提示里标注 |

### 安全约束

- **不允许删光所有页**：PDF 至少要保留 1 页。若范围会删掉全部页面，「删除」按钮会置灰并给出提示；
  只有 1 页的文档也会直接提示，不会弹删除对话框。
- 越界页码只忽略超出部分（如 10 页文档输入 `7-12`，生效的是 `7-10`）。
- 删除后视图自动落到剩余的有效页，不会出现空白或越界页号。
- 与旧版一样，删除是一次可撤销操作（「编辑 → 撤销」）。

### 技术实现

- 新增 `DeletePagesDialog`（`app/ui/dialogs.py`）：范围选择、页码解析（去重 / 排序 / 越界裁剪 /
  连续段合并显示）、实时摘要与按钮状态联动。
- `app/ui/main_window.py` 的 `do_delete_page()` 改为读取对话框返回的 0 基页索引列表，
  交给已有的 `ops.delete_pages()`（该函数本身已支持多页，按倒序删除避免索引漂移）。
- 中英文文案新增在 `app/i18n.py`；菜单标签同步改为「删除页面...」/「Delete Pages...」。
