# 轻PDF编辑器 v1.0.13

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

**高亮 / 下划线 / 删除线不再要求逐字精确框选**：用鼠标「划过」要标记的文字就能标上。
横向划一条细线、只框到词的一部分、框得偏一点都可以；但框外、行外、列外的文字完全不会被波及。

## 怎么用

1. 在工具栏选 **高亮**、**下划线** 或 **删除线**。
2. 在页面上按住鼠标左键，**大致朝要标记的文字划一下**即可，不必把每个字/词都完整框住：
   - 横向划过一行 → 该行被划到的词全部标记；
   - 竖向划过几行 → 这几行被划到的词都会标记；
   - 只框到词的左半边 → 这个词依然会被标记；
   - 框偏到行的上缘或下缘也能命中（±1.5 pt 容差）。
3. 松开鼠标即完成标注，可继续框选其它文字；误操作用「撤销」恢复。

## 判定规则

| 步骤 | 旧版（v1.0.12 及以前） | 本版（v1.0.13） |
|---|---|---|
| 选词 | `get_text("words", clip=框)`：单词必须**完全落在**拖框内 | 拖框碰到单词即命中（左右各 2 pt 容差） |
| 行 | 无行概念，框到哪算哪 | 拖框上下范围碰到某行 → 整行参与候选 |
| 框的高度 | 必须框住文字的高度 | 横向划一条细线也能标记整行 |
| 多余文字 | 容易漏标；框大则连带旁边内容 | 只标记命中行内、与框横向相交的词，其余一律不动 |

实现位置：`app/core/annotations.py` 的 `words_for_markup()`（纯函数，可独立测试）；
`app/ui/pdf_view.py` 的三个标记工具改为调用它。界面配色、布局、工具栏未改动。

## 验证

- 31 项断言全部通过，覆盖：
  - **降精度**：1 pt 高的横向细划、只框到词的三分之一、框边缘偏 2 pt、划过整行、竖向跨行；
  - **不乱画**：行间空白、页面空白、下边界之外、只框第 2 行时不碰第 1/3 行、只框一个词时不碰相邻词；
  - **兼容性**：旋转页面（未旋转坐标系内判定）、无文字层的空白页不报错；
  - **三种标记**：HighLight / Underline / StrikeOut 批注类型正确写入，原文保持不变。
- `app/` 与 `run_app.py` 全量 `compileall` 通过。
