# 轻PDF编辑器 v1.0.17

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

图章与骑缝章改用**毫米**为单位，印章大小按**红色印迹直径**计算；上传印章照片可一键**去除背景**；骑缝章位置只需上下调节，**所有盖章页同步**。

## 本次改动

### 1. 单位统一为毫米（mm）

| 项目 | 旧版 | v1.0.17 |
|---|---|---|
| 图章大小 | 像素宽（pt） | 印章直径（mm） |
| 骑缝章印章大小 | pt | 印章直径（mm） |
| 骑缝章距页边距离 | pt | mm |
| 骑缝章垂直位置 | 上/中/下/百分比 | 距页顶距离（mm） |

界面数值全部带 `mm` 后缀；内部按 `1 mm = 72/25.4 pt` 换算成 PDF 坐标，落位与显示一致。

### 2. 印章大小 = 红色印迹直径，不再按上传图片算

以往的「显示宽度」缩放的是整张上传图片；照片四周的白边会被算进尺寸，导致同一个数值盖出来的红章大小不一。
现在 `stamp_diameter_mm` 指的是**红色印迹本身的直径**：

- 去背景时先把图片裁到红章边界，整个裁后图就是红章；
- 不去背景时按红章像素占画布的比例反推缩放，红章直径仍等于设定值；
- 红色像素用 numpy 的红通道优势判定（无需 cv2，冻结包已内置 numpy）。

### 3. 印章照片去除背景

图章设置新增「去除照片背景」（默认开启）：以图片四边估计纸张底色，把接近底色的像素变透明，
暗色 / 高饱和 / 红色像素保留并做抗锯齿边缘；检测不到内容时回退原图，绝不误删印章。
处理结果与缩放后的图片均有缓存，实时预览不会因大照片变卡。

### 4. 骑缝章只上下调节、所有页同步

- 去掉「左右交替 / 全部贴右 / 全部贴左」选择，左右边由装订奇偶规律自动决定（奇数页右、偶数页左）。
- 位置只保留一个「距页顶距离（mm）」；插入时所有盖章页使用同一个绝对垂直坐标，
  改一个值整组盖章页同步上下移动。预览的红条同步反映统一位置。

## 验证

- 红章照片模拟（600×600 白底 + 300px 红环）：
  - 去背景后裁到 328×328，红直径 324px，白底透明；
  - 设 40 mm → 渲染红印迹实测 **40.10 mm**；不去背景时红印迹实测 **39.98 mm**（同样 40 mm）。
- 骑缝章 4 页统一 `top_mm=148.5`：各页落位 y 均为 `420.945 pt`（148.5×72/25.4），完全一致。
- 冻结 exe 字节码核验：版本 `1.0.17`，`app.ui.stamps` 含 `remove_background` / `red_seal_diameter_px` /
  `_rgba_array`，`insert_riding_stamp` 参数为 `margin_mm` / `top_mm`（不再有 `side` / `vpos`），numpy 已打包。
