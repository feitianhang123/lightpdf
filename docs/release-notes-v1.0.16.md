# 轻PDF编辑器 v1.0.16

> 精简版 PDF 编辑器 ｜ 基于 **PyMuPDF (MuPDF)** + **PySide6 (Qt)** ｜ 支持中文 / English
> 非官方软件，仅供学习交流，与任何商业 PDF 软件厂商均无从属或合作关系。

## 一句话

修复打印缩放：**「自定义比例」终于真正生效**——选 50% 时内容只占半张纸，预览和打印输出都如此。
「适合 / 缩小过大页面 / 实际大小 / 自定义%」现在在预览里能看出区别，所见即所得。

## 问题现象

打印一张横向发票时，在「页面缩放」里选择「自定义比例 50%」，预览里发票依然铺满整张 A4；
即使打印到 PDF，内容还是填满纸张，比例设置看起来完全无效。

## 根因

两处都把缩小的结果又放大了回去：

1. **预览**：`_paper_canvas()` 把内容用 `_fit_rect()` 无条件等比放大到纸张大小，
   缩放模式（含自定义比例）根本没有参与预览计算。
2. **打印**：`_draw_scaled()` 的自定义分支先把图像按百分比缩小，接着又调用
   `_fit_rect()` 把它重新放大到适合纸张——当图像比例与纸张接近时，50% 被抵消成 100%。

## 现在的规则

预览与打印输出共用 `_scale_rect()`，以「适合纸张」的矩形作为 100% 基准：

| 缩放选项 | 内容在纸上的大小 |
|---|---|
| 适合可打印区域 | 等比放大到尽量铺满纸张 |
| 缩小过大页面 | 按物理英寸换算，只有页面比纸大时才缩小 |
| 实际大小 | 按物理英寸 1:1 绘制，居中；超出纸面的部分裁切 |
| 自定义比例 | 以「适合」为 100%，50% 就是半张纸，200% 允许超出纸面并裁切 |

比例输入非法或为空时回退 100%，范围限制 1%~1000%。纸张方向仍只改变纸张形状；
v1.0.15 的「旋转内容适配纸张」复选框保持默认关闭。

实现位置：`app/ui/dialogs.py` 的 `PrintDialog._scale_rect()` / `_custom_percent()` /
`_paper_canvas()` / `_draw_scaled()`；界面布局、配色、工具栏均未改动。

## 验证

- 预览画布像素检查：横向内容「适合」宽 1200px →「50%」宽 600px →「200%」宽 2400px。
- 打印到 PDF 实测：50% 时黑色内容宽度约为页宽的 48.9%（差值来自打印机页边距），不再铺满。
- 「实际大小」按物理英寸换算：420×260 pt 页面在 1200px 长的 A4 预览纸上为约 599×371px。
- 冻结 exe 字节码核验：`app.version` 为 `1.0.16`，`PrintDialog` 含 `_scale_rect` / `_custom_percent`，
  且 `_scale_rect` 引用 `content_ppi` / `paper_ppi`。
