## 本次更新：全软件下拉菜单与输入框一眼可分

**问题**：「页面 → 拆分文档」里的「拆分方式」其实已经是下拉菜单，点击即可选「按页数均分 / 自定义范围」，
但它长得和旁边的输入框几乎一样，很难看出"这里可以点开选"。软件里其他下拉框也有同样的毛病。

**根因**：主题样式把 `QComboBox` 和 `QLineEdit` 写在**同一条规则**里（都是白底 1px 边），
而且 `QComboBox::drop-down` 只给了宽度、**没有绘制箭头**，所以下拉框完全没有自己的视觉语言。

### 改成了什么

| | 输入框 | 下拉菜单 |
|---|---|---|
| 背景 | 白色 | 淡绿色 |
| 边框 | 1px 浅绿细边 | **2px 绿色粗框** |
| 文字 | 常规 | 加粗、深绿 |
| 右侧 | 无 | **独立绿色按钮区 + 向下三角箭头** |
| 反馈 | 聚焦时边框变绿 | 悬停变亮、展开时箭头区高亮、禁用时整体变灰 |

- **全软件 20 处下拉菜单**一次性统一：拆分方式、删除页面范围、旋转、插入、页眉页脚、页码、
  水印、打印对话框（打印机 / 每张多页 / 顺序 / 装订 / 方向 / 打印内容 / 纸张 / 缩放……）、
  图片转 PDF、图章设置、文本编辑字体等。
- 展开后的**选项列表**也统一：绿框白底、行高加大、悬停浅绿、选中项高亮，点选更清楚。
- 「拆分方式」重点加强：更高、字号更大、箭头区更宽，并加了悬浮提示
  「点击右侧箭头展开下拉菜单，选择拆分方式」。

### 技术说明

- `app/ui/theme.py`：把输入框与下拉框拆成两套规则，新增 `::drop-down` 背景 / 分隔线、
  hover / `:on` / disabled 状态，以及 `QComboBox QAbstractItemView` 弹出列表样式。
- 箭头图标由 `apply_theme()` **运行时用 QPainter 绘制**成小 PNG（无需随包附带资源文件，
  源码运行和 PyInstaller 打包都可用）。这里绕开了 Qt 样式表的两个坑：CSS `border` 画不出三角（会变实心方块）、
  以及给 `::down-arrow` 写多条带状态的规则会额外冒出一个灰色箭头。
- `app/ui/dialogs.py`：`SplitDialog.mode` 设为 `splitMode` 以套用重点样式，并补上悬浮提示。
- 交互逻辑完全没有改动，下拉框依旧点任意位置即可展开，选项与回调保持原样。
